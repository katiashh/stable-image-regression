# Reported results

The CSV files contain the values reported in the revised manuscript.

- `main_results.csv`: Tables 1–3, including clean and attacked settings for Easy, Medium, and Hard regimes.
- `upper_tail_medium.csv`: Table 4, including p90 and p99 of the empirical local stability score under the Medium setting.
- `noise_free_ablation.csv`: Table 5.
- `runtime.csv`: Table 6.

All values are copied at the precision shown in the manuscript. The score `B` is an empirical diagnostic computed with the finite-step procedure described in the paper; it is not a formal certification bound.
