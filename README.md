# Stable Image Regression

This repository accompanies the paper:

> **Stable Image Regression via Adaptive Aggregation of Noisy Predictions and Input-Gradient-Regularized Fine-Tuning**

The paper studies adaptive aggregation of noise-perturbed predictions combined with input-gradient-regularized fine-tuning to improve the empirical accuracy--stability trade-off in image-to-scalar regression.
