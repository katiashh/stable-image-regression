# Data and checkpoint layout

The repository does not redistribute datasets or pretrained weights. Place the files locally using the following layout.

```text
data/
├── koniq/
├── koniq10k_scores_and_distributions.csv
├── KonCept512.pth
├── inceptionresnetv2-520b38e4.pth
├── wiki_crop/
│   └── age_split/
│       ├── train/images/
│       ├── train/labels.csv
│       ├── val/images/
│       ├── val/labels.csv
│       ├── test/images/
│       └── test/labels.csv
├── ShanghaiTech/
│   └── part_B/
│       ├── train_data/images/
│       ├── train_data/ground-truth/
│       ├── test_data/images/
│       └── test_data/ground-truth/
└── partBmodel_best.pth
```

## Datasets

- KonIQ-10k: use the official dataset and MOS annotations.
- IMDB-WIKI: use the official Wiki Images data and the split lists generated by `scripts/rebuild_age_split_lists.py`.
- ShanghaiTech: use Part B and its official image and ground-truth files.

The exact dataset papers and access instructions are cited in the manuscript. Do not commit the datasets or model checkpoints to the repository.
